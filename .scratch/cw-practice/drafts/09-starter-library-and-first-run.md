# 09 — Start useful practice immediately on a Mac

**What to build:** Install/run the app with a curated editable starter library and clear help, then verify a complete real Mac practice session.

**Blocked by:** 08 — Practice exchanges line by line with two station tones.

**Status:** draft — breakdown awaiting review

- [ ] Seed separate editable lists for KE2ISH, common terms, common prosigns, and short exchanges on first use; do not reseed over user edits or deliberately emptied lists.
- [ ] Include CQ, DE, K, R, TU, 73, QTH, RST, and QRS, with useful additional terms and correct editable spoken phrases.
- [ ] Include prosign meanings and verified continuous encodings; keep ordinary abbreviations distinct.
- [ ] Include short ordered exchanges for calling CQ, answering, reports, name/location, repeats, slower sending, and signing off; use KE2ISH as the learner station and a consistently identified example counterpart.
- [ ] Verify terminology, prosign use, and exchange wording against authoritative amateur-radio references; record sources and explain example callsigns are practice material.
- [ ] Document install/run instructions, data location, editing, settings, controls, supported input, and how to recover from reported audio/speech/save errors.
- [ ] Complete a real Mac session covering first run, saved edits, restart, both station tones, arrow/vi controls, hidden/reveal and highlighting, all reinforcement patterns, and cycle/shuffle.
- [ ] Confirm pending setting changes, interruptions during CW/speech/gaps, and terminal restoration on exit. Record automated results separately from human listening/visual checks.
- [ ] Preserve user data across application upgrades; demonstrate that reinstallation does not overwrite the library.

## Boundary

This delivers starter content and first-run usability. Earlier tickets own their feature validation; this is not a deferred correctness or cleanup phase.
